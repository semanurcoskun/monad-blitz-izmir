# monad-blitz-izmir
🎟️ Web3 Ticketing App (Monad Network)A decentralized, hybrid Web2/Web3 mobile ticketing application combining the seamless user experience of modern booking platforms with the security and ownership of blockchain technology.📖 About The ProjectThis project aims to revolutionize the ticketing industry (buses/flights) by introducing blockchain mechanics. Built for the Monad Blitz İzmir hackathon/event, the platform allows users to search for travel routes, securely lock seats, and complete purchases using cryptocurrency on the Monad Network.Upon a successful transaction, the user's ticket is minted as an ERC-721 NFT, granting true digital ownership and opening doors for secure secondary market transfers.🏗️ System ArchitectureThe project utilizes a hybrid architecture to balance speed (Web2) and decentralization (Web3):Frontend (Flutter): Provides a smooth, cross-platform mobile UI for searching routes and connecting Web3 wallets (via WalletConnect).Database (Firebase Firestore): Handles real-time data syncing, user authentication, and high-speed querying for available routes.Backend API (Python / FastAPI): Acts as the secure middle-layer. It handles complex business logic, concurrency control (preventing double-booking), and verifies Web3 transaction hashes before authorizing NFT minting.Blockchain (Solidity / Monad): EVM-compatible smart contracts handle the financial transactions and mint the NFT tickets to the user's wallet.💻 Tech StackMobile: Flutter, DartBackend: Python 3.12+, FastAPI, Uvicorn, PandasDatabase: Firebase (Firestore & Auth)Web3: Monad (Devnet/Testnet), Solidity, Web3.py / Web3dart✨ Key FeaturesAdvanced Route Filtering: Search by source, destination, date, airline, and budget (min_price, max_price).Smart Sorting: Order results by price or flight duration.Concurrency Control (Double-Booking Prevention): Implements a database-level transaction lock. When a user selects a seat, it is locked exclusively for them for 10 minutes to complete the Web3 payment.Crypto Payments: Seamless integration with Monad network for low-latency, low-cost EVM transactions.NFT Ticketing: Tickets are verifiable digital assets (NFTs) tied to the user's wallet address.🔌 API Endpoints (FastAPI)MethodEndpointDescriptionGET/Health check and API status.GET/flightsReturns a list of available flights based on query parameters (source, destination, date, min_price, max_price, sort_by).POST/reserve-seatLocks a specific seat for 10 minutes. Requires flight_id, seat_id, and user_id.POST/confirm-purchaseVerifies the Web3 transaction hash.
